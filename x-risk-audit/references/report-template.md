# 风控检测报告模板（report-template）

按此骨架输出。原则：**结论先行、每条可执行、区分"你发的"和"你关注的人发的"**。引用他人帖子保留必要原文（正当使用），但不扩散到报告之外。

---

## 骨架

```markdown
# X（Twitter）风控检测报告

- **检测对象**：@<handle>（昵称）的「正在关注」时间线 + 本人发帖 + 本人回复
- **检测时间**：<抓取日期>
- **检测口径**：<全部类别 / 仅PII / 仅凭据 / 仅话题>
- **样本量**：关注流 N 条（覆盖 <起>–<止>）、本人原创帖 N 条、本人回复 N 条
- **检测方式**：浏览器 DOM 抓取 → 规则引擎扫描（PII 正则+校验 / 凭据特征 / 敏感话题词库）→ 逐条人工复核

## 一、结论速览

| 检测面 | 结果 | 风险定级 |
|---|---|---|
| 你发的帖子 | <干净 / 发现 N 条问题> | <无风险 / 中 / 高> |
| 你关注博主的帖子 | 发现 N 条问题帖子，涉<类别摘要> | <中 / 高> |

<如有一条与用户本人直接相关的风险（如执法传闻），在此单独一句点出并指向明细章节。>

## 二、关注博主敏感内容明细

### 2.1 【高风险】<标题：一句话说清是什么>

- **博主**：<昵称 @handle>
- **链接**：<status URL>
- **内容摘要**：<概括，敏感原文可短引>

4. <长期底线：任何帖子不出现真实密钥、证件号、门牌住址>

## 五、覆盖度与局限

- <抓取窗口与滚动抓取的理论漏检>
```

## 填写要点

1. **定级口径**（与 `detection-rules.md` 一致）：高风险=涉本人安全的执法传闻、暴力煽动、歧视煽动、违法交易；中风险=色情低俗、争议言论、刷粉机器人；低风险=玩笑语境、粗口、误报排除项；干净=零有效命中。
2. **"你关注的人发的"≠"你发的"**：明细里必须写清"出现在你的关注流中"；定级和处置建议都只针对互动风险，不视为用户本人发布。
3. **每条明细必须有链接**，用户要能点进原帖核验。
4. **风险说明写因果关系**：不只是"这是敏感词"，而是"对你意味着什么"（限连坐、执法窗口、账号权重）。
5. **处置建议只建议、不代做**：本 skill 全流程只读，取消点赞/取关由用户本人在 X 上执行。
6. **干净也要写**：本人内容零命中时明确说"干净"，并附习惯提醒——这是报告的价值之一。
7. **样本量与窗口必须写实**：滚动抓取有漏检可能，注明覆盖起止日期，不夸大为"全量"。
