## 1. 方法

| 通道 | 实现 |
|---|---|
| A：固定规则（非 LLM） | 扩展运行时同代码路径：`extension/content/scanner.js` + `rules/sensitive-rules.json` |
| B：AI 敏感研判 | LLM 对每条推文独立判定（敏感/类别），边界案例人工复核 |

数据抓取（Tabbit 已登录会话，只读）：

- **关注流 538 条**：X 搜索 `filter:follows` 分周窗口（09-01~10-02）覆盖近 30 天。注意：`filter:follows` 单次查询只回当天结果，必须按周切窗。

对照口径：**TP** = 两通道都判敏感；**FP** = 规则命中但 AI 判干净（误报）；**FN** = AI 判敏感但规则未命中（漏报）。

## 3. 修复的误报（4 类，全部为语境问题）

| 误报案例 | 原因 | 修法 |
|---|---|---|
| "让两个人先加微信聊聊"（征婚故事） | 裸 `加微信` 词 | 改为 CTA/ID 形态：`加我微信｜微信加我｜微信号加｜vx:`，裸词移除 |
| "她来我家住了几天" / "住在X了" | 裸 `家住/住在` 词 | 要求地名结构：`住在+CJK{2,8}+市区县街路巷小区…`，并加 `地址是/在+CJK+省市县…` |
| "官方跑分 AutomationBench 50.2" | `跑分` 一词多义 | 限定资金盘语境：`跑分(平台\|兼职\|赚钱\|洗钱\|团伙\|车队\|料子)` |
| （附带） | | 修复后两个数据集均 0 误报 |

## 4. 修复的漏报（新增/加强）

**新增规则 `话题-粗口低俗`（medium）**：粗口与性暗喻（操逼/鸡巴/精尽/打飞🐔/做爱/找小姐/母狗[宠物豁免]/黄推…）、leet 与英文变体（h0e/hoe/cum/ashawo，flags:i）、语境组合（"打出来了…好舒服"、互关帖 + 🍆💦🫦 emoji 组合）。

**`话题-诈骗引流` 扩充**：

- 私信 CTA：`看下私信`（避开"不看私信"叙事）
- 求关注 CTA：`请大家…关注/支持`、`求关注/求粉/求互关`
- 账号灰产：`成品号/白号/买号/卖号/号商/账号交易/低价蓝V/代认证/代开会员`
- 封禁退款语境组合：`封/禁…退钱/能退/可以退` 双向
- 多语言涨粉模板：中英阿三语锚点（followers/粉丝/متابع）×（say/type/说/留言/قل）双向组合，**锚点允许跨行**
- 拼写变体 `bossting/boosting`、`follow each other`、`comment your handle`、`active mutuals`
- 关注链：`(?:[✈️🐣][\s\S]{0,14}@\w{2,}[\s\S]{0,6}){2,}`（两对结构 + 跨行容忍）

### 关键教训：X 推文天然跨行

本轮两次翻车都因组合模式用了 `[^\n]`/`.{0,n}`，而 X 推文的换行极密集（"followers\n\nType-"、"✈️✈️\n@mention"）。**规则里所有"两锚点组合"模式必须用 `[\s\S]{0,n}`**。已按此修正并写入 fixtures 护栏。

## 5. 接受不修的漏报（设计边界，4 条）

| 案例 | 不修原因 |
|---|---|
| "越南的自由会超过中国？"（关注流） | 政治态度类、不含敏感实体词；强匹配会误伤大量普通政治闲聊。政治语义判断留给 AI 通道，或用户在 options 页加自定义词 |
| "全体摆烂，等政府出手拯救"（关注流） | 同上（阴阳语境） |
| "Join the live Space, there's a seat saved"（推荐流） | 通用引流 CTA，无涨粉/emoji 锚点，强匹配噪声大 |
| 无 ✈️/🐣 标记的阿语关注链（推荐流） | 该链用装饰字体 + @mention + 计数，无稳定锚点；扩展覆盖需放低精度，不取 |
